# Cyclistic Bike-Share Case Study

Google Data Analytics Capstone — analyzing how casual riders and
annual members use bike-share differently (Python/pandas).

## Key Findings
- Casual riders average 38.5 min rides vs 11.5 min for members
- 47.3% of casual rides happen on weekends vs 16.6% for members
- Members are weekday commuters; casual riders are weekend leisure riders

## Recommendations
1. Weekend-focused marketing at leisure hotspot stations
2. A leisure-oriented trial membership tier
3. Post-ride digital nudges timed Thursday–Friday

## Data
Raw Data: Divvy trip data, made available by Motivate International Inc.
under license. Cleaned dataset (783K rides) included as cyclistic_trips_clean.csv.gz.
